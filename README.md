# Труд Крут — сайт РСО

Веб-сайт движения РСО (Российские студенческие отряды) на **Next.js (App Router)**.
Многостраничный портал с информацией о движении, региональной структуре и
инструментами для вступления.

## Разделы
- 🏠 Главная и «О движении»
- 🧭 Направления деятельности (`/directions`)
- 📰 Новости (`/news`)
- 🗺️ Карта отрядов (`/map`)
- 🤝 Вступить / найти отряд (`/join`, `/find-squad`)
- 🎓 Обучение (`/training`)
- ✉️ Контакты (`/contacts`)
- 🔧 Админка (`/admin`) и API-роуты (`/api`)

## Стек
- Next.js (App Router), React, TypeScript
- Данные региональной структуры в `src/content`

## Запуск
```bash
npm install
npm run dev      # http://localhost:3000
```

Сборка прод-версии:
```bash
npm run build && npm start
```

## Структура
- `src/app/` — страницы и API-роуты (App Router)
- `src/components/` — UI-компоненты
- `src/content/` — данные (регионы, структура движения)
- `public/` — статика и изображения
